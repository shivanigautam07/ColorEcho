# 🎨 ColorEcho – Color Memory Game

ColorEcho is an interactive **color memory game** built using HTML, CSS, and JavaScript. The game challenges players to remember and repeat an increasingly complex sequence of colors.

As the game progresses, each level introduces a new challenge, making the experience more exciting and testing the player's memory and concentration.

## 🧾 Overview

**ColorEcho** is a browser-based memory game designed to test your concentration and memory skills.

The game generates a sequence of colors that players need to remember and repeat in the correct order. With every successful level, the challenge increases and the sequence becomes more difficult.

This project was created to practice JavaScript concepts, DOM manipulation, event handling, and game logic.

## 🎯 How to Play

1. Start the game.
2. Watch the displayed color pattern carefully.
3. Remember the sequence.
4. Click the colors in the correct order.
5. Complete the sequence to move to the next level.
6. Each level adds a new challenge.
7. A wrong selection ends the game.
8. Restart and try to beat your previous score! 🚀
